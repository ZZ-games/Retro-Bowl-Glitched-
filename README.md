# Retro Bowl (Glitched)

A modded copy of [ZZ-games/retro-bowl](https://github.com/ZZ-games/retro-bowl).

## Mods

- **Glitched coaching credits** – you always have **999** coaching credits, and spending them
  (staff, facilities, free agents, morale/condition boosts, meetings) never takes any away.
- **Easy player upgrades** – open any player on *your* roster and the upgrade buttons
  (Throwing / Strength / Speed / Stamina, etc.) are unlocked. Each tap adds +1 to that stat,
  all the way to the max of 10, and costs no skill points. Every player's potential is raised to max.

## Play

Open `index.html` through GitHub Pages (Settings → Pages → deploy from `main`, root folder),
then play at `https://zz-games.github.io/retro-bowl-glitched/`.

Note: saves are stored in the browser per site, so this copy keeps its own save
separate from the normal Retro Bowl page.
